About

Free programming education for curious learners

CRACK THE CODE exists to make programming more accessible by pairing clear learning paths with practical coding exercises and guided challenge work.

Our mission

We want learners to build confidence through structured lessons, real challenges, and a strong coding habit.

Open source

The platform is designed to be transparent, maintainable, and welcoming to contributors from all backgrounds.

How to contribute

Fork the project, open a pull request, and share new tutorials, challenge ideas, or fixes to improve the experience for everyone.

How to report bugs

Open an issue in the repository with clear reproduction steps and expected behavior, so the team can triage and resolve it efficiently.

Run locally

Install Django, create a virtual environment, apply migrations, and launch the app using the commands in the project README.
